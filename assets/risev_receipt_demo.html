This is a self-contained UI prototype with sample data, animated receipt and locally generated PDF. It does not process real payments, send automatic WhatsApp messages or store customer information. Production integration requires Risev's backend, payment verification and approved messaging service.

Share receipt on WhatsApp

Your browser cannot attach a PDF directly to WhatsApp from this page. Download the PDF first, then attach it as a document in WhatsApp. On compatible phones, the main button opens the native share sheet.

The demo never sends a message automatically. Attach the downloaded PDF manually after WhatsApp opens. A WhatsApp Business API is required for direct server-side document delivery.
